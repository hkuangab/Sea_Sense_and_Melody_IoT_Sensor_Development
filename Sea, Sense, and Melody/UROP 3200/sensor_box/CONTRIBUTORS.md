# Contributors

This file lists all individuals who have contributed to the Sensor Box project,
in the order of their first contribution. Names are formatted as
"FAMILY NAME, Given name" to match the author block in each source file.

## How to add yourself

When you submit a pull request that adds, removes, or modifies source code,
please add a single line with your name, affiliation, and contact email in
the section below. Keep the list sorted alphabetically by family name.

## Recognition

Contributors are also credited in the author block at the top of every source
file they modified. The project follows the convention that the primary author
is listed first, followed by subsequent contributors who made substantial
changes (typically more than cosmetic edits).
